# Minizin — modelos convertidos para Minecraft Bedrock (laboratório)

Arquivos extraídos e convertidos de modelos originais com documentação de procedência.
**Geometrias JSON não são, por si só, mods Bedrock completos ou entidades jogáveis.**

- ice_and_fire: 192 poses/modelos Tabula exportados em geometry JSON (não animações).
- alex_caves: Atlatitan, modelo Java Citadel convertido.
- block_atlases: Waystones, Biomes O Plenty e Aether — .geo.json + PNGs de atlas.
- cataclysm: 41 modelos Java convertidos; os demais exigem outro parser/revisão.
- old_prototype_packs: Waystones/Mowzie, com protótipos .mcaddon.
- xaero_waypoints: exemplo JSON de importação, não o minimapa visual.
- distant_horizons: análise de fonte e dados LOD offline, não renderização nativa.

As fontes originais permanecem nos submódulos Git do repositório.
Registre e cumpra as licenças/autorizações aplicáveis ao redistribuir assets.
Renderização, IA, animações, worldgen e performance ainda devem ser validadas no Android.
