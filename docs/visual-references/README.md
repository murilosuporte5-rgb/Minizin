## 6. Instruções de implementação e QA para Codex

Para **cada** recurso original, verificar:

1. Versão exata do mod Java, arquivo/classe-fonte e licença.
2. Foto real da referência; modelo, textura e UV originais quando legalmente disponíveis.
3. ID do item ou bloco no Java e ID correspondente no Bedrock.
4. Aparência **no inventário**, **na mão**, **equipado**, **colocado no mundo**.
5. Receitas, efeitos reais, habilidades, durabilidade, sons, animações e interfaces.
6. Persistência após sair/entrar, morte, multiplayer, descarregamento de chunks.
7. Screenshot e Content Log reais do Android; não substituir por testes estáticos.

**Estados:** CONFORME / DIFERENTE / AUSENTE / NÃO TESTADO / BLOQUEIO TÉCNICO VERIFICADO.

Criar ou atualizar um arquivo de matriz ITEM_VISUAL_PARITY.md com as colunas:

| Mod | Java ID / versão | Referência visual | Bedrock ID | Inventário | Mão/equipado | Receita | Mecânica | Teste Android | Estado |
|---|---|---|---|---|---|---|---|---|---|

Não declarar "100% igual ao Java" só porque a renderização parece semelhante ou todos os JSONs foram gerados. **Imagens linkadas não são autorização para redistribuir assets.** Verificar licenças antes de distribuir PNGs, OGGs e modelos.
